# Мобильная версия и установка на Samsung

## Что изменилось

При ширине меньше 768 px приложение использует отдельные панели: компактный
header и меню, выбор POV и детали сцены в bottom sheet. Desktop sidebar не
монтируется. История имеет собственный scroll; нижняя навигация заменена меню,
поэтому она не конкурирует с composer. Поле растёт до шести строк и остаётся в
нижней части visual viewport, включая изменение высоты при клавиатуре.

В меню: Игра, Мир, NPC, Память, Ветки; отдельно мастерская, настройки и чтение.
Раздел веток объясняет текущие ограничения: варианты работают, именованные
ветки пока не реализованы. Мобильные варианты ответа: ↻ ‹ 2 / 3 ›.

Прокрутка следует за ростом ответа только пока читатель находится внизу.
ResizeObserver учитывает поздний рендер Markdown. После ручного скролла вверх
появляется «К последней сцене»; новые токены не возвращают читателя вниз.

## Почему нужен HTTPS

`http://192.168.1.57:8000` остаётся обычным браузерным доступом. Для service worker
и полноценной установки нужен доверенный HTTPS; исключение для localhost на ПК
не распространяется на LAN IP телефона. Пропуск предупреждения о недоверенном
сертификате не заменяет доверие CA.

Реализован локальный HTTPS без домена, туннеля или облачного прокси: собственный
CA на компьютере и сертификат для его LAN IP. Первичная установка доверия на
телефоне выполняется вручную один раз. Браузер не позволяет приложению сделать
это автоматически.

## Первичная настройка на компьютере

1. Выполни `stop.bat`, обнови ветку проекта.
2. Один раз запусти **`setup_https.bat`**. Он подготовит зависимости и frontend,
   создаст CA в `.runtime/tls`, сертификат сервера и `.runtime/https.json`.
   Запиши показанный адрес, например **`https://192.168.1.57:8443`**.
3. Запусти **`start.bat`**. Desktop откроется по прежнему HTTP, HTTPS будет работать
   параллельно с тем же приложением, БД и задачами генерации. `stop.bat` остановит
   оба listener-а. После настройки достаточно обычного двойного клика start.
4. Если Windows спрашивает доступ для Python — разреши для частной домашней сети.
   Телефон должен видеть TCP 8443 и для начальной загрузки сертификата TCP 8000.
   Приложение не меняет firewall и не открывает порты роутера автоматически.

Если автоопределение выбрало VPN/не тот адаптер, после остановки выполни в папке
проекта (подставь IPv4 компьютера из `ipconfig`):

```bat
.venv\Scripts\python.exe local_https.py --ip 192.168.1.57 --port 8443
start.bat
```

Закрепи этот IP в DHCP-настройках роутера. При смене IP повтори команду для нового
адреса; CA сохраняется, повторная установка доверия не нужна, но установленная
PWA со старым адресом требует переустановки. Сертификат сервера действует год;
повторный setup обновляет его тем же CA. CA действует десять лет.

## Установка сертификата на Samsung

1. На телефоне в той же Wi-Fi сети открой
   **`http://192.168.1.57:8000/api/local-ca`** (подставь свой IP/HTTP-порт).
   Сохранится `AI-RPG-Local-CA.cer`. Альтернатива — скопировать на телефон только
   `.runtime/tls/rootCA.cer` с компьютера.
2. Открой **Настройки → Безопасность и конфиденциальность → Другие настройки
   безопасности → Установить из памяти устройства → Сертификат CA**.
   Названия зависят от One UI: пункт может называться «Установить сертификат»;
   его можно найти поиском настроек по слову «сертификат».
3. Подтверди установку, введи PIN и выбери скачанный `.cer`. Нужен именно CA,
   не пользовательский/VPN или Wi-Fi сертификат. Android может показать
   предупреждение о доверии локальному центру сертификации.
4. Полностью закрой и снова открой браузер. Перейди на
   **`https://192.168.1.57:8443`**. Страница должна открыться без ошибки сертификата.
   Если ошибка осталась, проверь соответствие IP сертификату и установку CA;
   не используй «продолжить небезопасно» как способ установки PWA.

Ключи `rootCA.key` и `server.key` остаются на компьютере и не раздаются API.
Не пересылай их вместе с `.cer`. Этот вариант предназначен для доверенной
домашней сети: публичная многопользовательская авторизация в движке не добавлена.

## Samsung Internet

1. Открой доверенный HTTPS-адрес приложения и дождись загрузки.
2. Нажми значок установки **«+» в адресной строке** и выбери добавление/установку
   на главный экран. В версиях с другим меню: **≡ → Добавить страницу в → Главный
   экран**, затем подтверди установку приложения, если предложено.
3. Запускай **AI RPG Engine** с появившегося значка. При установке как веб-приложения
   оно открывается в `standalone`, без обычной адресной строки браузера.

Если создана только закладка с адресной строкой, проверь HTTPS без предупреждений,
перезагрузи страницу и воспользуйся значком установки PWA. Наличие и названия
пунктов зависят от версии Samsung Internet.

## Chrome на Samsung

1. Открой **тот же HTTPS-адрес** в Chrome и дождись загрузки страницы.
2. **⋮ → Установить и создать ярлык → Установить**. В некоторых версиях:
   **⋮ → Добавить на главный экран → Установить**.
3. Подтверди имя AI RPG Engine и запускай приложение с главного экрана.

Chrome и Samsung Internet имеют отдельные браузерные данные. Сейвы и ключ API
общие на сервере, но выбранный сейв и локальные настройки интерфейса могут
потребовать повторного выбора. HTTP и HTTPS тоже являются разными origin.

## Offline и обновление

PWA не превращает локальный движок в сервер на телефоне: для игры компьютер
должен работать. Без связи показывается отдельный экран с повторным подключением.
Service worker кэширует только статические файлы, не API/SSE, ключи или сейвы.
Новая версия service worker ждёт закрытия старых вкладок/окон; активная генерация
не прерывается принудительной перезагрузкой. После обновления проекта закрой все
окна приложения и открой его снова.

## Проверка и источники

Автоматизация проверяет четыре ширины, desktop, размеры composer при эмуляции
visualViewport, установочные файлы, service worker и восстановление после offline.
Это не заменяет физическую проверку Samsung Keyboard и установки в Samsung Internet.
