# Бюджеты запросов и подробность

Для новых профилей Сценариста, Генератора и Ведущего включён автоматический режим. Модель и подключение выбирает пользователь. В ручном режиме применяются сохранённые числовые потолки. Переключение на автоматику сохраняет их для возврата. API принимает `budget_mode: "auto" | "manual"`. Старый запрос с числовыми полями использует прежнюю ручную политику, включая прежний флаг определения окна.

Бюджет ограничивают возможности выбранной модели, доступный остаток общей операции и активные ручные потолки. Рекомендацию для мира определяют исходная идея и цели существующего `cast_preset`. На игровых ходах подборщик контекста использует текущую сцену, знания и POV. Перед отправкой сервер оценивает весь запрос, включая транспортную схему. Установленный проверенный токенизатор DeepSeek используется локально. Запас протокола и оценка UTF-8 при отсутствии токенизатора учитывают неопределённость. Фактический расход появляется только при наличии usage от провайдера.

Возможности DeepSeek берутся из официального каталога, для LM Studio используется окно загруженного экземпляра. Для совместимого сервера можно задать `COMPATIBLE_MODEL_LIMITS` как JSON, например `{"https://models.example/v1":{"my-model":{"context_length":65536,"max_output":8192}}}`. Для раздельных лимитов используйте `max_input` и `max_output`. Адрес должен совпадать с `COMPATIBLE_BASE_URL`. Доступные числовые метаданные из GET /models ограничивают результат даже при наличии серверной конфигурации. Для каждого предела применяется меньшее значение. Когда размер окна неизвестен, укажите проверенное значение в расширенных настройках. Денежный потолок требует известного тарифа. [Каталог DeepSeek](https://api-docs.deepseek.com/quick_start/pricing/)

В настройках создания мира и политике истории доступны Кратко, Сбалансированно, Подробно и Развёрнуто. Они задают плотность прозы внутри одного момента. Системное указание о подробности дополняет пользовательский стиль, соблюдая agency, правила канала и перспективу. Режимы из таблицы `DETAILS` задают ориентир видимого текста и запас для естественного завершения. Thinking получает дополнительное место внутри общего лимита ответа. Смысловая проверка мира сохраняет собственную политику Thinking Off.

Изменение политики действует со следующего нового хода. Перегенерация использует сохранённый контекст и параметры исходного запроса. При восстановлении Мастерская продолжает сохранённые фрагменты и учитывает уже зарезервированные и потраченные токены. История запросов содержит версию политики, источник характеристик, оценку входа, разрешённый выход, причины ограничений и данные провайдера о завершении. Старые снимки и журналы читаются в существующем формате SQLite.
