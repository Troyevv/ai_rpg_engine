# Сравнение «По моей идее» с утверждённым прототипом

Предыдущая реализация не была принята: она воспроизводила расположение блоков, но упрощала панели, выбор параметров, проверку, генерацию и результат. Эта итерация переносит оформление из исходных `atelier.css`, `settings.css`, `flow.css`, `App.tsx`, `Settings.tsx`, `Communication.tsx`, `Flow.tsx`.

Фиксированная браузерная версия эталона — `tests/fixtures/idea190-reference.zip`. Она обслуживается исключительно тестовым сервером. Production не импортирует симулятор, статический календарный каталог или демонстрационный редактор. Общий гравюрный asset взят из полного исходного архива.

| Элемент | Поведение прототипа | Поведение production | Отличия | Исправление |
|---|---|---|---|---|
| Шапка, поверхности, типографика | Гравюра, литературный заголовок, тёплые поверхности | Исходные размеры, шрифты, палитра Graphite и scoped CSS | Сохраняется реальный WorkshopShell; другие скины используют свои токены | Убрана приближённая палитра, перенесены исходные правила |
| Редактор | Постоянная подпись, счётчик, раскрытие, примеры с подтверждением | Те же элементы и лимиты, полноразмерный диалог | Статус честно указывает сохранение в текущей вкладке | Перенесены editor-tools, footer, модальные шапки и тела |
| Параметры | Пять строк с иконками, боковые панели | Те же пропорции, оттенки и drawer | Полные значения доступны при фокусе и в панели | Убрана техническая форма без структуры |
| Жанры | Основной выбор, оформленные дополнительные чипы | Существующая модель жанров и ограничения, чипы с состояниями | Backend остаётся источником проверки | Оформление и состояния выбора перенесены |
| Персонажи | Карточки масштаба, ручные числа, образец речи | Карточки, прежние counts/expressiveness, живой образец | Подсказки используют смысл действующих настроек | Select масштаба заменён карточками-radio |
| География и темп | Отдельные поля, пояснения рядом | Переиспользуемые CreationFields в структурированной панели | Нет отдельной модели настроек | Перенесены отступы, размеры, состояние фокуса |
| Календарь | Режимы, свой календарь, дата/время, праздники | Те же поля; каталог и предпросмотр действующего API | Реальные локализованные названия вместо демокаталога | Сохранены изменения #174/#189, дата разбита на три поля |
| Связь | Иконки каналов, плюс/отметка, раскрывающиеся особенности | Семь независимых checkbox-чипов, реальный каталог шести пресетов | Значения профиля и политика доставки берутся с сервера | Нативные видимые checkbox заменены визуальными состояниями эталона |
| Проверка | Заголовок этапа, карточка замысла, основные и остальные параметры | Та же композиция, read-only preflight и явный запуск | Нет выбора демонстрационного сбоя | Переработана целиком |
| Генерация | Журнал, полосы этапов, номера, статусы | Журнал из текущего job, реальные стадии и поток статуса | Нет искусственных процентов, ETA и таймеров | Завершённость привязана к origin_job версии |
| Ошибка и восстановление | Причина, сохранённый мир, доступные действия | Безопасный HTTP-диагноз и прежние resume/retry/stop/guards | Доступность повтора и бюджет определяет сервер | Действия pipeline сохранены, оформлены рядом с журналом |
| Результат | Карточка версии, публичный фрагмент, отметки проверок | Реальная версия, public_description, статус структуры/review | При отсутствии публичной аннотации нет вымышленного текста | Отдельная карточка результата вместо списка этапов |
| Авторский редактор | Демонстрационная карточка кампании | Существующая полная Мастерская с авторским подтверждением | Намеренно сохранён полноценный редактор #188 | Второй редактор не создавался |
| Движение | Drawer, раскрытия, выборы, активный этап | Единые 160/220 мс, направленные переходы, обратимое раскрытие, реальные статусы | Добавлено закрытие drawer и переход формы в сводку | Сохранён reduced motion, нет блокирующих таймеров |

## Проверка

Целевые размеры — desktop 1440 × 900 и mobile 390 × 844. Playwright сохраняет пары `reference-*` / `production-*` для пустого/заполненного экрана, каждой группы, связи, примеров, раскрытого редактора, проверки, генерации, ошибки и результата. Дополнительно проверяется Parchment, длинный текст, reload, клавиатура, reduced motion, валидация и изоляция черновиков.

Финальная визуальная сверка этой итерации пока не завершена. Результат будет обновлён после получения и просмотра новых браузерных снимков. Успешная сборка и тесты сами по себе не означают визуальную готовность.
