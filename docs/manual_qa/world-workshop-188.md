Карта ограничивает одновременно изображаемое окружение пятью соседями, показывает общее число и позволяет выбрать любого персонажа. Линии и направленный список строятся только из существующей серверной проекции. Создание/редактирование использует прежний API; добавленная запись открывается сразу. Смена участника не открывает повторно закрытое окно. Редактор остаётся доступным после изменения источника связи.

## Интерактивно проверенные экраны и действия

Настоящий production build React запущен с FastAPI, SQLite, jobs и SSE через `tests/e2e_server.py`. Работа в локальном Chromium: клики, ввод, select, загрузка файлов, Escape, Back, прокрутка, reload. LLM заменён штатными управляемыми тестовыми провайдерами; production API и сохранения не подменяются.

- Идея → настройки → генерация → обзор; сохранность текста идеи, новая история и пустой ввод. Прогресс и disabled-повторные действия.
- Импорт полного мира из `runtime_handoff/world.json`: 19 персонажей, 9 мест, 10 организаций, 18 направленных отношений, семейные связи, 19 фактов, 4 линии, 6 событий. Это тестовый мир, не данные HTML-прототипа.
- Поиск, карточки, переключение досье, вкладки, ручное поле, восстановление несохранённого ввода, конфликт сохранения, новая структурированная цель. Стресс-сценарий с 240 персонажами и описанием из 1000 повторов — отдельный Playwright E2E.
- Процедурные варианты лица/волос/кожи/палитры; отмена настроек, сохранение; свой PNG и неверный тип файла; изображения в мастерской и игре. Нейтральные варианты/стадии жизни дополнительно покрыты unit/backend тестами; физически все сочетания элементов не перебирались.
- Места, организация и selector связанных мест; отношения и семья; сюжеты, факты/знания, хронология; открытие связанных досье.
- Проверка мира: pending/running/error, reload во время обработки, отмена платного повтора без второго запроса, подтверждённый повтор и успешное завершение. UI не маскирует ошибку провайдера под ошибку мира.
- AI: инструкция → processing → reload → preview «до/после» → отмена подтверждения с возвратом фокуса → apply → история → rollback. До подтверждения состояние неизменно, после rollback полностью равно исходному. Затем восстановлен применённый пакет → Start Game → два Narrative-фрагмента/один выбранный ход.
- Экспорт JSON, импорт, история версий, восстановление; отмена удаления черновика, удаление и восстановление из корзины.

## Viewports, скины и доступность

Обзор и досье открыты на **360, 390, 430, 768, 1280, 1440, 1920 px**, проверены скриншотами и DOM-геометрией: горизонтального скролла документа нет. Дополнительные формы, портреты, AI-preview/подтверждение, история и ошибки проверены на 390 px. Поле при высоте 380 px прокручивается до кнопки сохранения; досье при 720×450 сохраняет доступ к действиям. Сокращение viewport моделирует недостаток места, но не заменяет проверку физической клавиатуры.

Все 17 скинов просмотрены на desktop/mobile; после изменения mobile-композиции отдельно пройдена форма поиска/выбора персонажей во всех 17 скинах (фокус, пустая выдача, геометрия без переполнения): Graphite, Cyberpunk, Industrial, Medieval, Arcane, Parchment, Gothic, Urban, Street, Noir, Terminal, Space, Post-Apocalypse, Biotech, Occult, Retro, Neon. Цвета/границы остаются skin-owned; Parchment использует Georgia, Noir/Occult — Courier, HUD-скины — Consolas. Контраст дополнительно измерен по computed solid colors для заголовка, приглушённого текста, неактивной навигации и основной кнопки во всех 17 скинах: минимум 5.23:1 для текста и 6.67:1 для основной кнопки. Это выборка, а не сертификат полного WCAG-аудита (градиенты, прозрачности и все состояния отдельно не измерялись). Проверены keyboard focus, Escape, Back, возврат фокуса, aria-required и живые статусы. E2E дополнительно проверяет увеличенный корневой размер текста 200% и reduced motion.

## Соответствие эталону и ограничения

Сопоставлены оболочка, обзор, карточки/досье, ручные редакторы, отношения/семья, тайны, сюжеты, лента, AI и mobile-композиция с HTML/CSS/JS и приложенным preview. Сохранены боковая колонка 238 px, книжные заголовки Graphite, портретная колонка досье, отдельная мобильная навигация, модальные редакторы и художественные SVG-слои.

Оставшиеся отличия имеют функциональные причины:

- Нет пейзажа/изображений мест — прямое требование #175.
- Реальные серверные стадии, revision и ошибки вместо demo-процентов/таймеров. Предпросмотр AI показывает реальную структуру и зависимости, не вымышленную демонстрационную статистику.
- У канонических событий/фактов/линий нет отдельных демонстрационных `title` и свободной даты: отображается существующий текст; дата форматируется Runtime, отсутствующая помечается неизвестной.
- Ручное сохранение идёт по полям с отдельной revision и историей; не имитируется атомарное «сохранить всё досье», которого действующий API не обещает. Связанные массовые изменения остаются в AI-editor pipeline.
- Дополнительные канонические поля, типизированные ссылки, обязательные идентификаторы структурированных записей и авторский режим сохраняются. Пустые необязательные/технические поля свёрнуты.
- Пагинация и ограниченная карта окружения позволяют работать с большими мирами; полный состав доступен через поиск/select. Детские/неподдерживаемые формы портретов нейтральны, графика не выдумывает каноническую внешность.

**Не проверено:** интерактивное открытие эталонного HTML (блокировка облачного браузера; обход не предпринимался); pixel diff двух живых страниц и точное совпадение анимаций прототипа; live DeepSeek; физические Android/Samsung Browser keyboard/Back и Safari; нативный browser zoom 200%. Увеличение текста и уменьшенный CSS viewport проверены, но не объявляются эквивалентом этих физических сценариев. Облачный браузер не видит localhost сервер этой среды; приложение проверено в настоящем локальном headless Chromium.
