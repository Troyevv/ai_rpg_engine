# #73 — варианты действий текущего персонажа

## Подготовка

```bash
RPG_DEV_TOOLS=1 python scripts/narrative_test_world.py --checkpoint choices
```

Используйте отдельную dev-БД и сервер из [README](README.md). Повтор команды
создаёт новое прохождение, сохраняя старое; `base` не изменён. Checkpoint уже
начат: три детерминированных хода проведены через обычные resolver/commit.
Платных вызовов модели при загрузке нет. Начальные шесть кнопок — фиксированный
пример для проверки UI, **не результат оценки качества LLM**.

Кирилл (`qa_kirill`) получил три player-owned evidence и refinement canonical
`personality.items.communication` (revision 1): говорит прямо и спокойно,
короткими утверждениями. Исходная карточка сохранила прежние уточняющие вопросы.
Есть цель разобраться в карте, намерение сравнить снимки, обязательство вернуть
Вере альбом, привычка рассматривать детали и отношения с Верой/Тимуром.
У Веры другой профиль: развёрнутые фразы с мягкой иронией и цель подготовить
выставку. Тайное письмо Олега знает только Олег.

## Действия и ожидаемый результат

1. Откройте прохождение: шесть `{action,speech}` предложений и свободный ввод.
   Просмотр/перезагрузка не меняют цели, эмоцию, намерения, personality или Knowledge.
2. Введите «Рассматриваю фотографии. Тимур, покажи этот угол крупнее».
   В Extraction diagnostics найдите `Choice context / controlled actor`: actor_id
   Кирилла, актуальная canonical манера речи, активные motivations, его направленные
   отношения и known/suspected факты. Письмо Олега отсутствует в этом блоке.
   GM-only данные рядом нужны для Extraction, но не разрешают раскрывать секреты.
3. Сравните предложения после хода: разные решения, а не шесть перефразировок;
   характерные и правдоподобные нетипичные действия; реплики учитывают адресата.
   При узком выборе допустимо меньше шести. Язык соответствует активной игре.
   Не должно быть предложения спросить об неизвестном письме или его содержимом.
4. Введите «Вопреки привычке, не проверяю детали, а предлагаю рискнуть».
   Нет отказа «не по характеру». Непосредственно предложение/клик не переписывает
   personality; только обычное подтверждённое развитие по правилам #67.
5. Перезагрузите игру → следующий ход. Canonical профиль и обязательства сохранены;
   недавний фактический ввод влияет на wording, не создаёт скрытый score.
6. Смените управляемого персонажа на Веру и сделайте ход. В choice context теперь
   её actor_id, стиль и цели. Реплики Кирилла не становятся её recent_player_expression,
   даже если она присутствовала при них. Переключитесь обратно для сравнения.
7. Regenerate последнего хода: используется записанное исходное состояние/ветка,
   без обучения на отвергнутом варианте. Выберите прошлый response variant: возвращаются
   его snapshot и choices. Rollback возвращает before-state без следов предложений.
   После отката последнего seed-хода revision communication снова 0; выбор прежнего
   варианта возвращает revision 1. Не копируйте данные между ветками вручную.
8. Наблюдение «Мир без героя»/background: choices пусты, персонаж не получает
   добровольные действия от модели. Заблокированный can_act также не получает choices.

Детерминированное покрытие: `tests/test_narrative_choices.py` (projection, POV,
свободный ввод, provenance, property-тест отсутствия мутаций, start → turn →
reload → next turn, control, regenerate/variant/rollback); desktop/mobile —
`frontend/e2e/choices.spec.ts`. Точное литературное качество и семантические
утечки в реальном ответе модели проверяются вручную, не сравнением строк в CI.
