**P2 — необязательный continuity beat блокирует явно заданный вопрос игрока.** Владельцы: `backend/runtime_v3/continuity.py`, `backend/runtime_v3/context_contract.py`, контракт #136. Продуктовый код не изменён.

2. Narrative: Вера предлагает спросить о библиотеке и упоминает фонд старых карт; не принимает новых решений за игрока.
3. Extraction создаёт Event `ev_turn2_vera_library` с `player_assertion=completed_interaction` и `player_evidence`, равным полному действию игрока. Дополнительный `continuity_beats[0]`: `actor_id=qa_kirill`, `kind=question`, `source_event_id=ev_turn2_vera_library`, `basis_ids=[qa_map]`, `status=open`; дублирующего `player_evidence` в beat нет.

Ожидание: структурно согласовать подтверждение с принятым Event либо диагностировать/отбросить необязательный beat, сохранив agency-защиту. Явно заданный вопрос не должен превращаться в новый неподтверждённый выбор из-за вспомогательной аннотации. Контракт Extraction требует `player_evidence` для EXTERNAL **decisions** и говорит, что обычному диалогу beat не нужен.
