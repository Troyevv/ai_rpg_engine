Ожидание: структурно согласовать подтверждение с принятым Event либо диагностировать/отбросить необязательный beat, сохранив agency-защиту. Контракт Extraction требует `player_evidence` для EXTERNAL **decisions** и говорит, что обычному диалогу beat не нужен.
