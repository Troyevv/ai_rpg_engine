4. `continuity.apply` требует отдельное поле для **любого** beat EXTERNAL actor, вызывает неремонтируемый `continuity_external_decision`; job `6df3bcc7099a46c996e6d92921693325` получает `error`, без repair.

Ожидание: структурно согласовать подтверждение с принятым Event либо диагностировать/отбросить необязательный beat, сохранив agency-защиту. Явно заданный вопрос не должен превращаться в новый неподтверждённый выбор из-за вспомогательной аннотации. Контракт Extraction требует `player_evidence` для EXTERNAL **decisions** и говорит, что обычному диалогу beat не нужен.

Детерминированный replay исходного before + Narrative + Extraction через `StateResolver` подтвердил тот же код ошибки. Состояние, предыдущий History, turn и variants исходной ошибки не изменились.

Рекомендуемое исправление у владельца: согласовать обязательность provenance с типом beat и связанным Event; добавить регрессию явного вопроса и отрицательные проверки неподтверждённых EXTERNAL decisions/background.
