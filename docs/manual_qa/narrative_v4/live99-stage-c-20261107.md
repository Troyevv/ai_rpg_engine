## Бюджет и запуск

Один дополнительный лимит **$2 для retest и Stage C вместе**. Одноразовая запись
stage_c_authorization в историческом ledger привязана к каталогу и исходным
счётчикам. Resume не обновляет allowance; неизвестный исход останавливает весь
платный прогон. Новые действия ограничены 120 резервами, calls — 320; это safety
caps, не цель по количеству. Платные сценарии выполняются последовательно.

Перед dispatch резервируется весь provider input window и configured output cap.
Тарифы сверены с официальной DeepSeek pricing: deepseek-flash / V4.1-Flash-1017,
1M context, peak uncached input $0.30/M, output $1.20/M, cached input $0.006/M.
Off-peak вдвое дешевле; guard считает консервативно peak/cold.
Снимок источника: `/workspace/work/stage-c-preparation/pricing.html`.

Результаты каждого действия включают intent, before/after, Delta, diagnostics,
request IDs, raw responses, usage/finish_reason, UI projection и reload. Независимый
provider-streams сохраняет каждый chunk до передачи потребителю. Historical
snapshots/History/variants и расходы не переписываются.

Retest использует завершённую Narrative Social/005, Campaign/014, Knowledge/005
через явный production Retry. Старые Extraction не считаются каноном; это один
необходимый post-fix retest, не автоматическое повторение при resume. Phone Retry
сохраняет уже принятое чтение. Старый Family save уже находится за due: он остаётся
нетронутым, boundary повторяется на новом таком же #78 pregnancy checkpoint.

Переход группы в Stage C требует законченного retest и отдельного evidence-bound
semantic review по State/History/Knowledge/agency. Held-группа не продолжается.
Одного HTTP 200 или saved status недостаточно. Новые реальные ходы используют
текущие Narrative/Extraction prompts; Retry намеренно сохраняет исходный контекст.
