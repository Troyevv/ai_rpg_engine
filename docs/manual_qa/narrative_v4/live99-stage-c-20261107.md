request IDs, raw responses, usage/finish_reason, UI projection и reload. Независимый

snapshots/History/variants и расходы не переписываются.

через явный production Retry. Старые Extraction не считаются каноном; это один

semantic review по State/History/Knowledge/agency. Подтверждённый атомарный отказ

валидный temporal последнего Extraction/repair. Прочие held-группы не продолжаются.
Одного HTTP 200 или saved status недостаточно. Новые реальные ходы используют
текущие Narrative/Extraction prompts; Retry намеренно сохраняет исходный контекст.

  завершение живого звонка при смерти/недееспособности остаётся непроверенным.
  Последний диалог после смены на Нину получил ложное присутствие Веры в prose и
  ложную свидетельскую запись в History (#226). Saved status этого шага не является
  semantic pass; отдельный hashed group-hold блокирует дальнейший resume группы.
- **Knowledge:** новые message facts имеют read provenance и ограниченных получателей;
  в выполненных сценах не обнаружена передача скрытого письма Олега. Запланированная
  цепочка ложного сообщения → исправление → устаревание не выполнена из-за #222.
