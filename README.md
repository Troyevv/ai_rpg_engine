# AI RPG Engine

Локальный генератор сценарных основ для текстовых ролевых игр на базе LLM.

Проект разделяет подготовку игры на два этапа:

1. **Сценарист** — получает краткое описание желаемой игры и формирует полный сценарный план: персонажей, отношения, завязку, локации и открытые сюжетные линии.
2. **Генератор выжимки** — превращает утверждённый сценарный план в подробную структурированную выжимку, которую затем можно использовать как контекст для ролевой LLM.

Интерфейс написан на **Streamlit**, а модели запускаются локально через **LM Studio**.

## Возможности

- выбор локальной модели из LM Studio;
- ручная загрузка и выгрузка модели из памяти;
- настройка размера контекста;
- настройка `Eval Batch Size`;
- включение и выключение Flash Attention;
- перенос KV-cache на GPU;
- отдельные параметры генерации для сценариста и генератора выжимки;
- потоковая генерация текста;
- остановка генерации с сохранением уже полученного результата;
- доработка сценарного плана через последующие сообщения;
- Markdown-отображение результатов;
- сохранение сценарного плана и итоговой выжимки в `.md`;
- возможность начать новую игру без перезапуска приложения.

## Как работает

Общий пайплайн выглядит так:

```text
Описание игры
    ↓
Сценарист / LLM
    ↓
Сценарный план
    ↓
Проверка и правки пользователем
    ↓
Генератор выжимки / LLM
    ↓
Полная Markdown-выжимка для RPG
```

Сценарный план можно несколько раз перерабатывать. При новом запросе текущая версия плана передаётся модели как актуальное состояние, поэтому модель должна изменить только запрошенные части и вернуть полный обновлённый вариант.

После утверждения плана вторая стадия получает:

- сценарный план;
- системный промпт генератора;
- обязательный шаблон выжимки.

На их основе модель формирует итоговый Markdown-документ.

## Структура проекта

```text
ai_rpg_engine/
├── app.py
├── llm.py
└── prompts/
    ├── idea_prompt.md
    ├── summary_prompt.md
    ├── summary_template.md
    ├── example_summary.md
    └── system_prompt.md
```

### `app.py`

Основное Streamlit-приложение.

Отвечает за:

- пользовательский интерфейс;
- состояние текущей игры;
- выбор и настройку модели;
- запуск сценариста;
- запуск генератора выжимки;
- потоковый вывод;
- остановку генерации;
- скачивание результатов.

### `llm.py`

Слой работы с LM Studio.

Использует:

- LM Studio REST API для получения списка моделей, загрузки и выгрузки;
- OpenAI-compatible API LM Studio для генерации текста.

По умолчанию приложение ожидает LM Studio по адресу:

```text
http://localhost:1234
```

### `prompts/idea_prompt.md`

Системный промпт сценариста. Определяет правила создания сценарного плана.

### `prompts/summary_prompt.md`

Системный промпт генератора итоговой выжимки.

### `prompts/summary_template.md`

Структура, которой должна следовать итоговая выжимка.

### `prompts/example_summary.md`

Пример готовой выжимки.

## Требования

- Python 3.10+;
- LM Studio;
- локальная LLM, совместимая с Chat Completions API;
- достаточно RAM/VRAM для выбранной модели и размера контекста.

Python-зависимости:

```text
streamlit
openai
requests
```

## Установка

Клонировать репозиторий:

```bash
git clone https://github.com/Troyevv/ai_rpg_engine.git
cd ai_rpg_engine
```

Создать виртуальное окружение:

```bash
python -m venv .venv
```

Активировать его.

Windows:

```bash
.venv\Scripts\activate
```

Linux/macOS:

```bash
source .venv/bin/activate
```

Установить зависимости:

```bash
pip install streamlit openai requests
```

## Настройка LM Studio

1. Установить и запустить LM Studio.
2. Скачать нужную локальную модель.
3. Запустить Local Server.
4. Убедиться, что сервер доступен на:

```text
http://localhost:1234
```

Приложение автоматически получает список моделей через LM Studio API.

## Запуск

```bash
streamlit run app.py
```

После запуска Streamlit выведет локальный адрес веб-интерфейса, обычно:

```text
http://localhost:8501
```

## Работа с приложением

### 1. Выбрать модель

В боковой панели выбрать модель, доступную в LM Studio.

Перед загрузкой можно задать:

- размер контекста: `8192`, `16384` или `32768` токенов;
- `Eval Batch Size`;
- Flash Attention;
- размещение KV-cache на GPU.

После этого нажать **«Загрузить»**.

При загрузке новой модели текущие загруженные модели предварительно выгружаются.

### 2. Создать сценарий

В поле сценариста коротко описать желаемую игру.

Например:

```text
Современность. Главному герою 24 года. Он переезжает в новый город
и заселяется в обычное общежитие. Хочу много бытовых сцен,
живых отношений, юмора и постепенной романтики.
```

Сценарист создаст полный план игры.

После генерации можно написать дополнительное требование, например:

```text
Сделай отношения между соседями менее дружелюбными в начале,
а романтическую линию более медленной.
```

Модель получит существующий сценарный план и должна вернуть его обновлённую полную версию.

### 3. Создать выжимку

После утверждения сценария запускается генератор выжимки.

Он использует сценарный план и `summary_template.md`, после чего создаёт подробный Markdown-документ для дальнейшей RPG-сессии.

### 4. Скачать результат

Из боковой панели можно скачать:

```text
idea.md
summary.md
```

## Параметры генерации

В интерфейсе отдельно настраиваются параметры двух стадий.

Для сценариста:

- `temperature`;
- `max_tokens`.

Для генератора выжимки:

- `temperature`;
- `max_tokens`.

Это позволяет использовать более творческие настройки для разработки идеи и более стабильные настройки для финальной структурированной выжимки.

## Загрузка моделей

`llm.py` использует LM Studio API:

```text
GET  /api/v1/models
POST /api/v1/models/load
POST /api/v1/models/unload
```

При загрузке передаются параметры:

```text
context_length
eval_batch_size
flash_attention
offload_kv_cache_to_gpu
```

Генерация выполняется через OpenAI-compatible endpoint:

```text
/v1/chat/completions
```

с включённым streaming.
